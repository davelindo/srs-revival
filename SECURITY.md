# Security and device data

The enabled KnOS console is unauthenticated and unencrypted. Restrict TCP 2320
to the maintenance client on a trusted network; never expose it to the Internet.
Console commands can alter memory, configuration and flash.

For a sensitive report, open a project issue requesting a private conversation.
Keep device dumps, credentials and sensitive details out of the issue.
[Contact the project](https://github.com/davelindo/srs-revival/issues)
